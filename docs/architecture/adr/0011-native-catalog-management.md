# ADR 0011: 自作商品の運営管理

- Status: Accepted implementation direction, 2026-09-13. 本番販売開始の承認ではない。
- Extends: ADR 0006、0009、0010。

## 判断

既存のGoogle運営者認証で確認した主体を使い、Shared securityが所有する `native_catalog_operators` で自作商品・在庫の管理権限を別に確認する。Shopifyの店舗や発送権限を管理権限へ読み替えない。既存の運営者を自動登録しない。期限付き権限の登録・停止はDB管理者の作業とする。

専用の `DATABASE_CATALOG_MANAGER_URL` と `bloombox_catalog_manager` ロールを使う。通常の購入アプリ・決済ワーカーへ管理権限を追加しない。権限行は専用関数で共有ロックし、処理前後にDB時刻で権限期限とログイン期限を確認する。停止操作は進行中の管理トランザクションと直列化する。

Catalogは商品・価格と変更履歴、Inventoryは販売用在庫と数量訂正履歴を所有する。個々のコマンドは状態と履歴を同じトランザクションに保存する。商品は下書きで作成し、別の保存操作で公開・受付を変更する。購入済みの価格スナップショットは更新しない。

各操作は期待バージョンと送信番号を持つ。古い表示からの上書きを拒否し、同じ運営者・送信番号・内容の再送は追加更新しない。同じ送信番号の内容変更は拒否する。在庫の補充は正の増分、数量訂正は正負の増分を記録する。予約数を下回る訂正は禁止する。販売用在庫は支払済み・未出荷の商品を含めない。

## 境界・代替案

UIの非表示だけでは権限を守れないため、読み取りと毎回のServer Actionで認証し、同一Originを検査する。フォームの運営者IDや権限は受け付けない。管理者全員への暗黙の許可やDBオーナー接続の共用は採用しない。画像は既存の許可ホストに限定し、アップロード基盤は追加しない。

## 展開と復旧

0022と権限SQLを適用し、期限付きの明示的権限と専用接続を設定してから利用する。今回はテストDBだけを対象とする。商品登録・公開は注文受付停止を解除しない。実在庫数や商品価格を推測して本番へ登録しない。

停止時は管理権限を無効化して新規管理操作を止める。商品・在庫・履歴の削除では戻さない。誤登録は履歴と現在の予約数を確認し、最新バージョンへの訂正として保存する。旧版の在庫予約・確定・解放は追加テーブルと共存する。
