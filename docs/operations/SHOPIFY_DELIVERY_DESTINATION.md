# Shopify配送先の構造・地域確認

2026-09-11時点。決済保存→価格照合→配送期限の確認を通った注文に対し、別のAdmin API照会で配送先の構造と承認済み地域を確認します。`ReconcileShopifyPayment`の`destination`は秘匿化した判定を返します。追加の`acceptance`には任意注入の[注文確定処理](SHOPIFY_ORDER_ACCEPTANCE.md)の結果を返します。公開経路・発送開始は未接続です。

## 地域方針

地域方針はFulfillment所有の`DELIVERY_COVERAGE_POLICY`に集約しています。現在は`PENDING`で、全件`COVERAGE_NOT_APPROVED`となり、住所自体のAPI照会もしません。全国配送、離島対応、地域別の追加料金を推測で決めません。

今後、事業者が確定した都道府県の許可リストと除外郵便番号の前方一致リストを設定します。郵便番号プレフィックスは、承認された具体的な除外条件だけに使用します。離島を自動判別する機能ではありません。空の許可リスト、未知/重複の都道府県、不正なプレフィックスは`COVERAGE_INVALID`として拒否します。追加送料・地域別リードタイムは未対応です。

構造と地域が一致した`STRUCTURALLY_VALID_AND_COVERED`も、住所の実在、宛名の本人性、電話番号、番地/建物の配送可能性、郵便番号と市区町村の一致、在庫、配送業者のサービス、注文の受け入れを保証しません。これらの確認が完了する前に発送を許可してはいけません。

## 必須項目と最小取得

正式な注文の`shippingAddress`から国・都道府県コード・郵便番号・宛名・市区町村・住所1行目だけを一時的に取得します。請求先を配送先へ流用しません。日本以外、欠けた宛名/市区町村/住所行、未知の都道府県、不正な郵便番号、対象外地域は理由を付けて保留します。郵便番号の全角数字・ハイフン表記は既存の正規化ルールで扱います。

Shopifyの都道府県コード`JP-01`〜`JP-47`を、既存の標準順序の都道府県リストへ変換します。英語/日本語の表示名から都道府県を推測しません。未知コードは保留です。

構造確認の照会では、氏名・市区町村・番地・郵便番号・都道府県を結果、監査、Outbox、ログ、DBへ追加保存しません。住所本文はInfrastructure内で検証後に破棄し、Applicationへは判定だけを返します。API応答の一時メモリ保持は発生します。電話、メール、請求先、建物補足、位置情報、ギフト本文はこの照会で取得しません。承認済みの注文確定に進む場合だけ、別の最終照会で建物補足・電話を取得し、Order所有の暗号化スナップショットに保存します。

## 障害・同時更新・期限

既存の決済照会に住所フィールドを追加せず、決済保存後の別照会にすることで、保護された顧客データのアクセス拒否が入金保存を妨げない構成にしています。店舗・注文ID・テスト区分・APIバージョンを固定し、住所照会時の注文更新日時が決済照会時と一致しない場合、またはキャンセル済みの場合は`ORDER_CHANGED`で保留します。配送不要の注文も保留します。

同じ通信境界の5秒上限、256KB応答上限、リダイレクト禁止、no-store、JSON/通貨情報と分離した住所スキーマ検証を使用します。権限拒否、GraphQLエラー、通信障害、異なる店舗/注文/テスト区分、不正な応答は詳細を含まない`ShopifyDeliveryDestinationUnavailableError`として伝播します。欠落した住所（null）による保留と、照会に失敗した状態は区別します。

照会失敗後も保存済みの決済記録は残り、再実行で重複書込せずに進められます。成功結果を返す直前に購入準備をもう一度読み、配送期限と詳細情報の保持期限を再確認します。住所照会中の日本時間の午前0時越えでも、先に確認した日付のまま受け入れません。

複数回の読取は注文確定の原子性を保証しません。注文確定では最新の版・配送条件・金額・住所スナップショットを改めて検証し、担当モジュールのトランザクションで保存します（任意注入の注文確定Gatewayで接続済み）。API更新日時だけを恒久的な住所同一性や発送承認に使ってはいけません。

## 本番前提と証跡

Shopifyの保護された顧客データへの権限・承認は、実店舗で確認が必要です。今回の合成テストはその承認や実店舗からの住所取得の証跡ではありません。公開経路/Inbox workerへの接続、本番Gateの有効化、実店舗APIアクセスは行っていません。

参照: [MailingAddressの正式フィールド](https://shopify.dev/docs/api/admin-graphql/2026-07/objects/MailingAddress)、[保護された顧客データ](https://shopify.dev/docs/apps/launch/protected-customer-data)、[Shopifyの日本住所コード例](https://github.com/Shopify/worldwide)。

Domainと内部ワークフローのテストで、地域未承認時のAPI非呼出、構造/国/コード/郵便番号/対象外判定、PIIを含まない結果とエラー、権限拒否後の決済保持・再試行、注文更新、住所照会中の配送期限越えを確認します。実際の郵便番号・地域設定・追加料金・配送可能性の受け入れ試験は残件です。

DB移行・環境変数・依存・権限の追加はありません。ロールバックは新しい配送先照会/評価とワークフロー接続を戻します。既存の決済・監査・Outbox記録は保持します。
