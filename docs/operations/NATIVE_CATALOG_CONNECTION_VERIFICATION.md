# Google運営者ログインと商品・在庫管理の接続検証

2026-09-13。mainの `b54ed78459ae60ebfe0528b7dec8c29932c3bd49` に対し、既存の実Google OAuth設定、実ブラウザー、隔離したローカルPostgreSQLを使って確認しました。認証・保存処理のコード変更はありません。

## 確認した接続

- 正規オリジンは `http://localhost:3000`。実Googleのアカウント選択から運営ページへ戻り、登録済み担当者として認識されました。
- 既存の発送用DBと分けたローカルDBに0001〜0022を適用し、専用の `bloombox_catalog_manager` 接続と、既存の登録済み運営者1名への2時間の検証権限を設定しました。
- ランタイムはPreview、新規注文受付は無効です。Google OAuth設定元の環境ファイルは変更していません。接続情報・認証情報・運営者識別子はGitやこの記録に含めていません。
- 管理画面の表示から保存まで、実際の画面上のフォームを操作しました。保存先はローカル専用DBで、合成フォーム応答ではありません。

## 操作結果

| 操作 | 観測した結果 |
| --- | --- |
| 実Googleログイン | 登録済み運営者として復帰し、商品・在庫管理を表示 |
| 商品を下書き登録 | 1件保存。下書き・受付停止、確認用価格1,000円 |
| 初期在庫を補充 | 0→3、補充履歴1件 |
| 在庫を−99訂正 | 拒否。数量3のまま、入力値−99を保持 |
| 在庫を−1訂正 | 3→2、訂正履歴1件 |
| 変更前の別タブから+1を保存 | 古いバージョンとして拒否。数量2を維持 |
| 商品名と価格の編集 | 同じ商品を更新。確認用価格1,000→1,100円、商品変更履歴2件 |
| 運営権限を無効化後、開いたままの別タブから保存 | 操作権限なしとして拒否 |
| 無効化後に管理画面を再読込 | Not Found表示。商品情報を返さない |
| 検証権限を復旧後に再読込 | 保存済みの商品・在庫を再表示 |
| ログアウト後に別タブを再読込 | Not Found表示 |

価格・在庫・商品はすべて接続確認用であり、実際に販売する数量・価格の登録ではありません。最終状態は下書き・受付停止、販売用在庫2、予約0です。注文・支払・発送は作成していません。

DBを読み取り、商品変更履歴2件・在庫変更履歴2件が確認済み運営者と一致することを確認しました。不正入力・競合・権限停止後の要求では履歴や数量が増えていません。専用接続がsuperuserでなく、ロール作成・予約数更新・注文参照・履歴削除の権限を持たないことも確認しました。[個人情報を含めない検証結果](evidence/native-catalog-connection-20260913.json)を添付します。

## ログアウトの留保

最初のログアウト操作後はログイン表示が残り、再読込してもログイン中でした。再操作でログアウトでき、その後、実Googleでログイン→管理画面→運営ページ→ログアウトの手順を2回再試験したところ、それぞれ一度の操作でログアウトできました。別タブでの閲覧拒否も確認しています。

最後の再試験では、Cookieの値・OAuthパラメータを記録しないローカル診断を行い、ログアウト応答がセッションCookieの削除を返し、後続の要求にセッションCookieがないことも確認しました。診断は確認後に取り外しました。

初回未反映の原因は未特定です。再試験の成功を根本原因の解消やコード修正の証拠とは扱いません。ブラウザー遷移直後の操作を含む再現条件の調査は残件です。認証・CSRF・Originの検査は変更していません。
