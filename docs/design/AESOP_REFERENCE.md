# Aesop リファレンス・デザインガイド（再現用）

Version 1.0 · 2026-10-04 · 対象：参考サイト [aesop.co.jp](https://www.aesop.co.jp/) のトップページ

このガイドは、Aesop 日本サイトの**デザインの規律**（色・文字・余白・部品・文体）を、自作サイトで再現できる形に分解したもの。BloomBox の正本は [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) と [`globals.css`](../../src/app/globals.css) の `:root` であり、このガイドはそれを置き換えない。採用する場合は第 10 章の手順でトークンだけを差し替える。

## 0. 読み方と信頼度

| 印 | 意味 |
| --- | --- |
| 【実測】 | 2026-10-04 に Aesop のページから `getComputedStyle` などで取得した値（1024px 幅のデスクトップ表示） |
| 【観察】 | スクリーンショットと本文から読み取った構成・雰囲気。数値は持たない |
| 【推定】 | 実測できなかったため、再現用に当方で決めた値。Aesop の実値とは限らない |

- 取得したのはトップページ 1 枚、1024px 幅の表示のみ。モバイル、ホバー、スクロール連動、他ページは未確認。
- 取得時は Cookie バナーが画面下にあり、全体が少し暗く見えた。写真の明るさの記述は割り引いて読む。

## 1. 権利と模倣の範囲

再現するのは**考え方と数値の関係**であり、素材ではない。

| 使わない | 理由 | 代わりに |
| --- | --- | --- |
| Aesop のロゴ、ボトルや店舗の写真、コピー、商品名 | 第三者の著作物・商標 | 自社の写真、自社の言葉 |
| Suisse Int'l、Zapf Humanist（実際に使われている書体） | 商用ライセンスが必要。ファイルも未提供 | 第 3 章の代替書体 |
| 「寓話」「書斎」などの世界観の直接の借用 | ブランド固有の物語 | 自社の物語（花、贈る行為）を同じ構造で語る |

「Aesop に似ている」ことを売りにしない。BloomBox が Aesop の一部と誤解される表現（紛らわしい配色＋同じ文体＋同じ構図の組み合わせ）は避ける。

## 2. 原則（8 つ）

1. **語りが先、商品が後。** 商品棚の前に、短い読み物ブロックを置く。買う理由を先に渡す。【観察】
2. **色は商品が持つ。** UI にブランド色を塗らない。アクセントは写真の中の商品と、小さな文字ラベルだけ。【観察・実測】
3. **強弱は大きさと余白で作る。** 太字・影・色帯で主張しない。見出しは大きくて細い（weight 400）。【実測】
4. **直角と細線。** 角丸 0、影なし、境界は 1px。【実測】
5. **ボタンは透明＋細枠。** ベタ塗りは「閉じる」など機能上必要な場面だけ。【実測】
6. **純白・純黒を避ける。** 紙色の背景と墨色の文字。【実測】
7. **面の明度を章ごとに切り替える。** 明るい紙色の面と、写真や暗色の面を交互に置く。【観察】
8. **1 ブロック 1 メッセージ。** 1 つの章に 1 つの見出し、1 つの説明、1 つの操作。【観察】

| 対象 | 値 | 根拠 |
| --- | --- | --- |
| 枠線ボタンの hover | `background-color`、`color` を 0.25s ease-out | 【実測】 |

## 4. 再現用 CSS（トークン）

下の `:root` は、Aesop 風の見た目を作るための**別テーマ**。BloomBox の既存トークンと名前が衝突しないよう `--ref-` を付けた。そのまま使う場合は、第 10 章の対応表で既存トークンへ写す。

```css
:root {
  /* color */
  --ref-paper: #fffef2;
  --ref-ink: #333333;
  --ref-ink-soft: #666666;
  --ref-dark: #252525;
  --ref-accent-label: #945c26;
  --ref-hero-scrim: linear-gradient(to bottom, rgba(0,0,0,.25), rgba(0,0,0,.6));

  /* type */
  --ref-font-sans: "Inter", "Noto Sans JP", "Hiragino Sans", Meiryo, sans-serif;
  --ref-text-h1: 36px;
  --ref-text-h2: 30px;
  --ref-text-label: 16px;   /* H3 を大文字・太字・字間 1px で使う */
  --ref-text-body: 16px;
  --ref-text-small: 14px;
  --ref-text-badge: 12px;   /* Aesop は 11px。可読性のため 12px に上げる */
  --ref-leading-heading: 1.4;
  --ref-leading-body: 1.7;

  /* shape */
  --ref-radius: 0;
  --ref-border: 1px solid currentColor;
  --ref-control-height: 48px;

  /* motion */
  --ref-motion-fast: 250ms;
  --ref-motion-tab: 500ms;
}
```

## 5. 部品の仕様と CSS

### 5.1 枠線ボタン（主要な操作）

見た目：透明、1px の細枠、直角、右に細い矢印。文言は「〜を見る →」「〜を探す →」。

```css
.ref-button {
  display: inline-flex; align-items: center; justify-content: center; gap: 12px;
  min-height: var(--ref-control-height);
  padding: 13px 24px 12px;
  border: var(--ref-border); border-radius: var(--ref-radius);
  background: transparent; color: inherit;
  font-size: var(--ref-text-small); line-height: 1.5;
  transition: background-color var(--ref-motion-fast) ease-out, color var(--ref-motion-fast) ease-out;
}
/* 紙色の面の上：hover で墨を塗り、文字を紙色にする */
.ref-button:hover { background: var(--ref-ink); color: var(--ref-paper); }
/* 写真の上：hover で紙色を塗り、文字を墨にする */
.ref-button--on-image { color: var(--ref-paper); }
.ref-button--on-image:hover { background: var(--ref-paper); color: var(--ref-ink); }
```

hover の反転は【推定】（実測は transition の対象のみ）。矢印は SVG で `aria-hidden`、文言は消さない。

### 5.2 ヒーロー

- 全幅の写真、暗幕（`--ref-hero-scrim`）、**中央揃え**の 4 段：キッカー（小）→ 見出し（30px）→ 説明（14〜16px）→ 枠線ボタン。【観察】
- 見出し・本文・枠線は紙色。写真が遅く読み込まれても、暗い背景の上に文字を出す。
- 下部中央に細い線のインジケーター、左下に小さな円形の再生・停止。どちらも主張させない。【観察】
- 高さは 512px（1024px 幅）。BloomBox では `min-height: 560px` 程度から調整する【推定】。

### 5.3 章見出し（中央）

```css
.ref-section-title { margin: 0 0 10px; text-align: center; font-size: var(--ref-text-h2); font-weight: 400; line-height: 1.33; }
.ref-section-lead  { margin: 0 auto 48px; max-width: 640px; text-align: center; font-size: var(--ref-text-small); color: var(--ref-ink-soft); }
```

### 5.4 商品カード

```css
.ref-card { display: grid; gap: 0; }
.ref-card__badge { margin: 0 0 12px; font-size: var(--ref-text-badge); color: var(--ref-accent-label); }
.ref-card__image { aspect-ratio: 1 / 1; width: 100%; object-fit: contain; background: transparent; }
.ref-card__category { margin: 24px 0 8px; font-size: var(--ref-text-small); color: var(--ref-ink-soft); }
.ref-card__name { margin: 0 0 12px; font-size: var(--ref-text-small); font-weight: 700; line-height: 1.1; }
.ref-card__desc { margin: 0 0 24px; font-size: var(--ref-text-small); color: var(--ref-ink-soft); }
.ref-card__price { margin: 16px 0 0; font-size: var(--ref-text-body); }
```

並びの順序（上から）：バッジ、画像、カテゴリ、商品名（太字）、説明、サイズ選択、価格（「（税込）」を添える）。カードに背景色・枠・影を付けない。列は 3 つが目安、横スクロールの送りは小さな矢印。【観察】

### 5.5 選択ボックス（サイズなど）

枠線のみの四角形、高さ 40px（BloomBox では 48px に上げる）。ラベル「サイズを選択」は小さく、選択中の値を大きめに表示する。【観察・実測】

### 5.6 読み物ブロック（左：文字、右：大きな画像）

```text
[キッカー(小)]                     ┌────────────────┐
[見出し 30〜31px・2〜3行]           │   大きな画像    │
[本文 16px・墨・弱]                 │  (暗めの情景)   │
[枠線ボタン →]                     └────────────────┘
```

- 文字カラムは幅約 280〜410px、左余白約 112px。【実測】
- 画像は暗めで、書斎のような情景。人物は断片（手・指）だけ。【観察】
- 左右の入れ替えで、章ごとに変化をつける。

### 5.7 カテゴリのタイル

縦長の写真を 5 枚並べ、写真の下にラベルだけを置く（「スキンケア」「ボディ＆ハンド」など）。写真の上に文字を載せない。【観察】

### 5.8 タブ

```css
.ref-tab { padding: 15px 35px; margin-right: 5px; font-size: 24px; line-height: 1.3; color: var(--ref-ink-soft); border-bottom: 1px solid transparent;
  transition: border-color var(--ref-motion-tab), color var(--ref-motion-tab); }
.ref-tab[aria-selected="true"] { color: var(--ref-ink); border-bottom-color: var(--ref-ink); }
```

`role="tablist"`、`role="tab"`、`aria-selected` を使う。矢印キーで移動できるようにする。

### 5.9 フッター

背景 `#252525`、文字は紙色 14px、リンク間は 5px＋下 8px。【実測】グループ分けされたリンク集と店舗案内を置く。BloomBox では既存の `SiteFooter`（法務・配送情報を保持）の配色だけを変える。

### 5.10 Cookie バナー

画面下に全幅、背景は紙色。左に説明文（12px）とポリシーへのリンク（下線）、右に墨色ベタ塗りの「閉じる」。【観察】広告計測の同意 UI は、BloomBox では承諾と拒否を同じ視覚的な強さにする（`DESIGN_SYSTEM.md` §11）。Aesop の「閉じる」のみの構成は**そのまま真似しない**。

## 7. 写真の撮り方

- 彩度は低め、暖色寄り、影は深い。映画のスチルのような質感。【観察】
- 商品写真：無地の淡い背景に商品だけ。1:1 に揃える。
- 情景写真：人物は手・手首・指だけ。木、本、琥珀色のガラスなど素材感のあるものを添える。
- 暗い写真の上に文字を載せるときは、必ず暗幕を重ねて、紙色の文字を使う。

**BloomBox に置き換えるなら**：花束、包装紙、リボン、手書きのカードなどを同じ規律で撮る（低彩度、暖色、断片的な人物、1:1 の商品）。ただし BloomBox は「花の色が主役」なので、彩度を落とし過ぎない。

## 8. コピーの書き方

| 型 | Aesop の例（要約） | 守る点 |
| --- | --- | --- |
| 問いかけの見出し | 香りを通じて問いを投げかける | 名詞で終えるか、短い問いにする。2 行以内 |
| 説明は 2 要素 | 機能 ＋ 香り（または素材） | 効果の数字で押さない。1 文 40 字前後 |
| ラベルは一言 | 「愛され続ける製品」「新たな製品」 | 色や形で煽らない。「限定」「残りわずか」は使わない |
| 結びの引用 | 偉人の短い言葉 | 引用元を明記。**自社のコピーで書く**か、権利の確認できる引用のみ |

- 文末は「です・ます」か名詞止め。感嘆符と絵文字は使わない。
- 造語や外来語の商品名は、意味を 1 行で補う。

## 9. アクセシビリティと BloomBox の制約（Aesop を超えて守る点）

Aesop の値のうち、BloomBox の方針と衝突するものは、次のように読み替える。

| Aesop の値 | BloomBox での扱い | 理由 |
| --- | --- | --- |
| body 12px | **16px** | `--text-body`。日本語の可読性 |
| バッジ 11px | **12px 以上** | `--text-meta`。10px 以下禁止（`DESIGN_SYSTEM.md` §9） |
| 選択ボックス 40px | **48px 以上** | `--control-height` |
| 「閉じる」のみの Cookie UI | **承諾と拒否を同じ強さ** | 同意 UI の方針 |
| 画像に埋め込まれた情報 | **使わない** | 重要情報は文字で |
| 色だけで状態を示す | **文言を併用** | 状態を消さない原則 |
| 暗い写真に小さい文字 | 暗幕で 4.5:1 以上を確認 | 本文の基準 |

focus は `:focus-visible` で 2px のアウトライン（紙色の面では `#333`、暗い面では紙色）を必ず出す。Aesop のサイトで focus の見た目は未確認。

## 10. BloomBox への適用手順

> BloomBox の現行デザイン（白・ミントのグラデーション・角丸のピル型ボタン）と Aesop 風（紙色・墨・直角の枠線）は**別の方向**。ブランドの方針を変える判断は事業側の決定であり、このガイドだけでは決まらない。以下は「採用すると決めた場合」の手順。

### 10.1 トークンの対応表

| BloomBox の既存トークン | 現行値 | Aesop 風の値 | 備考 |
| --- | --- | --- | --- |
| `--paper` | `#ffffff` | `#fffef2` | ページ背景 |
| `--ink` | `#0b0b0d` | `#333333` | 本文・見出し |
| `--ink-soft` | `#626873` | `#666666` | 説明 |
| `--surface` | `#f4f5f7` | 紙色より少し濃い色（例：`#f4f2e4`【推定】） | 補助面。コントラストを再計算 |
| `--footer` | `#000000` | `#252525` | フッター |
| `--accent` | `#13785f` | 変更しない（または `#945c26`） | focus と選択色。変更するなら白・紙色に対する 4.5:1 を再確認 |
| `--radius-pill` | `999px` | `0` | ボタン形状 |
| `--radius-media`／`--radius-card`／`--radius-panel` | 8 / 12 / 16px | `0` | 角丸の廃止 |
| `--accent-gradient` ほか mint 系 | ミント | 使わない（主操作を枠線ボタンへ） | 主操作の視認性は第 10.3 節で確認 |

### 10.2 手順

1. ブランド方針を決める（Aesop 風へ寄せるか、部分採用か）。**ここは事業の判断**。
2. `docs/design/DESIGN_SYSTEM.md` の該当節（§4 カラー、§6 形状、§7 部品）を、同じ PR で更新する。
3. `globals.css` の `:root` だけを書き換える。コンポーネント側に色の直書きをしない（`pnpm check:design` が検出する）。
4. 主操作を枠線ボタンにする場合：`.primary-button` の背景をトークン化し、**主操作と副操作の強さの差**を残す（例：主操作は墨のベタ塗り、副操作は枠線）。
5. 写真を差し替える（第 7 章）。素材は自社のものを使う。
6. 390 / 768 / 1440px と 320px の狭幅で確認する。長い日本語、税込価格、エラー文も確認。
7. `pnpm check:design` と、変更範囲に応じた型・lint・build。全体変更は `pnpm check:ci`。
8. スクリーンショットを `docs/design/evidence/` へ保存し、`VERIFICATION.md` に記録する。

### 10.3 適用前のチェック

- [ ] 主操作が「一番目立つ」ことを、白黒に落として確認した（枠線だけだと弱くなりやすい）
- [ ] 紙色 `#fffef2` の上で、すべての文字が 4.5:1 以上
- [ ] 暗幕つきヒーローで、写真が差し替わっても文字が読める
- [ ] 角丸 0 にしても、入力欄の境界が `--control-border`（3:1 以上）で識別できる
- [ ] 状態（売切れ・エラー・処理中・プレビュー）が文字で伝わる
- [ ] 他社の素材（ロゴ・写真・コピー・書体）が混ざっていない
