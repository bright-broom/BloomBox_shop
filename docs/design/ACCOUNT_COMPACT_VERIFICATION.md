# マイページの余白・アイコン改善

2026-09-14。会員特典・購入履歴・プロフィールを、同じ顧客情報のまま短い画面で見渡せるよう再配置した。認証・DB・注文所有権・ランク計算・割引条件は変更していない。

## レイアウト

- 大きな左ナビをアイコン付き横ナビへ変更。PCの概要部分は会員特典：プロフィール＝1.618：1、購入履歴は下段全幅。
- スマホは特典→履歴→プロフィール。共通24pxを基準に、内部余白14.83px・ページ上下38.83pxを黄金比で算出。スマホのページ上下は24px。
- 先行案の注意は常時表示。全ランクと適用条件、プロフィール・ログアウトの説明はnative detailsで参照可能。
- 名前・メールと支払/発送の項目名をアイコン化し、読み上げ名は保持。詳細への矢印リンクは48×48px・注文ごとの識別可能な名前を持つ。ログアウト、支払/発送の状態、主要ナビには文字を残す。

## 確認記録

比較元は公開SHA `decdb45fb05a24fc3066e1b5fab8c13924b74022`。架空データの `/preview/account?state=empty`、Chrome、1440px幅、disclosureを閉じた状態で `.account-page` の高さは2,517px→995px（約60%減）。見本用の案内も含む計測であり、全顧客・全画面の固定値ではない。

| 確認 | 結果 |
| --- | --- |
| 320 / 390 / 768 / 1440px | document幅とviewport幅が一致、横はみ出しなし |
| 注文詳細の矢印 | 全リンクに注文番号付き読み上げ名、操作領域48×48px |
| 注文詳細への遷移 | 矢印から該当サンプル注文の詳細・金額を表示 |
| 注文なし | 空状態と花を選ぶ導線を表示。初回の空状態では不要な「最新のご注文へ」を非表示。ページ送り後の空ページには先頭へ戻る導線を残す |
| 注文あり | 商品・注文番号・日付・購入時金額・支払/発送状態を維持 |
| 未ログイン・期限切れ・読込失敗 | 注文を表示せず、該当する案内/alertと復旧導線を維持 |
| 最高ランクBOUQUET、320px | ランクと割引率を横並びで表示 |
| ランクの説明 | クリックで全4ランク・条件を表示、Enterで開閉 |

スクリーンショットでPC・390px・320pxの見本を確認した。実機Safari・スクリーンリーダーの実操作は今回の確認に含まない。顧客の個人情報を含む画像は保存しない。全般の検証方法は [VERIFICATION.md](VERIFICATION.md)、デザインルールは [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) を参照。

`pnpm check:ci`（静的検査、型、lint、単体テスト、build）は成功。空ページからの復帰と、アイコンだけのリンクを注文ごとに区別できることを回帰テストに追加した。DBの更新・migrationは不要。
